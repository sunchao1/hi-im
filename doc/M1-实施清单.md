## 目标

交付 **最小可冒烟栈**：Hub + Redis + hubclient 测试桩 + unicast 脚本；**不含** gateway、msgsvr、群聊、WS。

**M3 总验收**（档 C §11.3）：

| 项 | 标准 |
|----|------|
| Compose | `make m3-smoke` 退出码 0 |
| 范围 | publish/unicast 路径通 |
| 边界 | **不**验收群聊、浏览器 Demo |

- [x] `common.sh` — `wait_ready hub`、`log_tail`

  2. 起 consumer 容器（后台或 compose service）

## 常见误区（档 C 对齐）

| 误区 | 正确 |
|------|------|
| M3 加 gateway 测群聊 | M3 仅 hub+hubclient unicast |
| 在主仓写 msgsvr 代码 | msgsvr 在 hi-im-msgsvr 仓 |
| 主仓一个 Dockerfile 打所有服务 | 每子仓自带 Dockerfile |
| 删掉 hi-im-core 自有 compose | 保留；主仓负责全栈 |
